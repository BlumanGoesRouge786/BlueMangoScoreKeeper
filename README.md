# Blumango's Table Tennis Scorekeeper
### Table-tennis scorer designed to accept manual point determination input from user 

  This program was created, at first, as a "multi-sport" scorekeeper that would be used for multiple different sports and scoring systems in general. But eventually, just to keep it simple, we just began with table-tennis since most other sports required time tracking libraries and... yeah... it's a bit too much if we want anything to get done in time. So, the original creator (yours truly) decided to stick with table-tennis for a start. 

  Other sports and scoring systems are to be added to code in a future time.
