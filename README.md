# Blumango's Table Tennis Scorekeeper
### Table-tennis scorer designed to accept manual point determination input from user 

  This Program was created originally as a ** "multi-sport' ** scorekeeper that will account for multiple different sports and scoring systems in general. But eventually, for the sake of simplicity, we just began with table-tennis since most other sports required time tracking libraries which is a bit too much if we want anything to get done in time. So, the original creator decided to stick with table-tennis for a start.
